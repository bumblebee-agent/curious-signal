### Inkling-2-Mini in 5.4 GB Memory

LookAtMyQuant is a quantization compiler that selects codes for model parameters to minimize output damage while adhering to a specific size budget. The tool achieves a 12× lower Kullback-Leibler KL divergence than Q4_K_M on the Gemma 4 E2B model at equivalent file sizes. Shin Megami Boson developed LookAtMyQuant 2, which compresses Qwen3.5-4B to 1.23 GB and solves 330 of 540 exact-answer math problems, outperforming Prism ML’s Bonsai 2 Ternary 4B which solves 328. The recipe applies post-training quantization using trellis codes, Fisher information-based bit allocation, and distillation on digit-weighted math solutions. A 26.4B physical version of the same approach compresses Inkling-2-Mini to 5.38 GB, matching the original model’s GSM8K performance at 41% smaller size than Unsloth’s UD-Q2_K_XL. The Qwen3.8-27B variant reduces to 7.2 GB and matches the original BF16 model on GSM8K while exceeding Unsloth’s UD-IQ2_XXS on HumanEval, MMLU, and GSM8K. The runtime utilizes custom Apple Silicon Metal kernels to deliver high inference speeds, with the 5.4 GB Inkling-2-Mini model reaching 1,807 tokens per second during prefill. Speculative decoding with a 4-bit DSpine drafter doubles decode speed on Apple silicon by proposing tokens in a single pass. The system supports self-calibrating adaptive fallback that pauses drafting when acceptance rates drop, ensuring bit-exact greedy parity. Developers can install the runtime via pip or use the `lamq` command-line interface to generate text or chat with the compressed models. The compiler measures parameter impact, allocates bits within a budget, and builds the quantized model through a series of named jobs runnable on Modal. Recent improvements include Softmax-Fisher token table ranking and mid-training equal-byte row reallocation to further reduce KL divergence. The project is open source under the MIT license, with all code, plans, and benchmark results available on GitHub. ## Tools and Smaller Signals

- [PcapAnalyzer – self-hosted pcap analyzer with 27 problem detectors](https://github.com/sebaandrada-cell/PcapAnalyzer): PcapAnalyzer is a free, open-source beta tool that identifies network faults within seconds by analyzing uploaded .pcap or .pcapng captures locally on the user’s machine. The software employs 27 detectors to examine TCP connectivity issues, path anomalies, name and address services, application responses, tunnel statuses, and security threats such as port scans and cleartext logins. It also assesses capture quality by flagging limitations like truncated packets or one-way traffic that might skew results. The interface provides Wireshark-style views including packet lists, expert info, and flow diagrams, while an optional AI investigation feature allows users to ask follow-up questions using their own Anthropic API keys. The application generates PDF reports and supports both Spanish and English interfaces with light and dark themes. Users can run PcapAnalyzer via Docker Compose or by setting up a local development environment with Python 3.9, Node 20, and tshark. The tool does not store credentials or telemetry, and it encrypts captures during optional AI analysis before deleting them after a period of inactivity. Developers can contribute to the project by reporting issues with synthetic or anonymized public sample captures on GitHub.
- [Signal restricts mobile screenshots as it confronts ‘existential threat’ of AI surveillance](https://techcrunch.com/2026/11/21/signal-restricts-mobile-screenshots-as-it-confronts-existential-threat-of-ai-surveillance/): Signal announced on Friday that it is restricting users' ability to take screenshots within its secure messaging app. President Meredith Whittaker cited the integration of agentic AI into operating systems as an existential threat to user privacy. She argued that Windows, Android, and macOS platforms now allow AI agents to scan screen information, thereby undermining Signal's capacity to guarantee data privacy. Whittaker stated that sensitive data gets captured and stored by local databases or remote servers under OS-level AI control. This process removes the data from Signal's oversight and jeopardizes the privacy of all conversation participants. The company previously blocked screenshots in its Windows application by default to mitigate these risks. Signal is now implementing similar screenshot restrictions on Android and iOS devices. Users retain the option to disable these settings, though Whittaker warned that doing so breaks the app's privacy guarantees. She acknowledged that this measure is incomplete because it does not prevent other methods of unauthorized data access by AI agents.

This timeline extends beyond the one-year deadline for legally binding agreements urged by the International Committee of the Red Cross, who emphasized the urgent need for restrictions due to civilian casualties in conflicts across Ukraine, Gaza, and Sudan. Russia, Israel, and the United States acted as primary obstacles to a faster resolution, with Russia delaying proceedings by challenging the agenda and the United States initially proposing a five-year window for nonbinding guidelines. The United Nations secretary-general and Pope Leo previously supported the call for immediate, legally enforceable rules to address the risks posed by semi-autonomous systems and drones.
- [Lean verification of the Riemann Hypothesis](https://leanprover-community.github.io/blog/posts/riemann-hypothesis/): The Lean and Mathlib communities have officially verified a proof of the Riemann Hypothesis submitted by Levent Alpöge. On November 20, 2026, Alpöge released a Lean library consisting of 17 million lines of code that formalizes this proof. A joint statement from these groups, endorsed by the Lean Free Software Foundation and the Mathlib Initiative, confirms the correctness of the work. The verification process relied on the fact that the codebase depends directly on Mathlib, a well-established mathematical library. Community members compiled the code and confirmed that it builds without errors or failures. They also isolated the statement of the Riemann Hypothesis within Mathlib and compared it against the theorem proved in Alpöge’s library. Two independent software tools confirmed that the library proves the exact statement found in the standard library. The raw proof export was then validated by multiple proof checkers, including Lean’s official kernel and third-party tools implemented in different programming languages. These external checkers operate with formal proofs that they cannot accept false theorems, thereby addressing potential concerns about flaws in Lean’s logic. The verification team ensured the checks ran on a static export of the proof to prevent interference from any potentially malicious source code. The community acknowledges the contributions of numerous individuals who provided resources for this extensive verification effort. They now anticipate further mathematical analysis to explain the new ideas presented in the proof.
