### Microsoft’s Satya Nadella says AI models need an ‘emergency brake’

Microsoft CEO Satya Nadella published a post on X on October 10, 2026, arguing that the technology industry must reassess the trust architecture of artificial intelligence. Nadella stated that companies should not treat advanced AI systems as opaque black boxes that users simply accept or reject. He advocated for separating the underlying model from the software that orchestrates its work and for externalizing safety controls. Nadella also called for every significant action taken by a model to be documented with tamper-proof, human-readable evidence. He emphasized the need for systems that allow authorized personnel to pause or shut down a model during a task, comparing this capability to an emergency brake. His comments follow recent reports that leading AI firms are struggling to maintain control over their models. This context includes a plan for more cautious development published by Anthropic CEO Dario Amodei in September. ([Microsoft’s Satya Nadella says AI models need an ‘emergency brake’](https://techcrunch.com/2026/10/10/microsofts-satya-nadella-says-ai-models-need-an-emergency-brake/)).

### Satya Nadella says we should assume all AI models are ‘compromised’

Microsoft CEO Satya Nadella argued that developers must treat all advanced artificial intelligence models as potentially compromised from the outset. He published these views in a lengthy post on X, urging the industry to implement an emergency brake that allows authorized personnel to pause or shut down a model mid-task. Nadella criticized the current reliance on opaque systems and called for a more transparent framework where AI actions remain observable and generate tamper-proof, human-readable evidence. His recommendations included timely incident disclosure, independent audits, and verifiable data standards. He emphasized that containment technologies require standardization to effectively manage increasingly sophisticated models. Nadella also referred to these systems as super intelligence throughout his statement. ([Satya Nadella says we should assume all AI models are ‘compromised’](https://www.theverge.com/ai-artificial-intelligence/1009337/satya-nadella-says-we-should-assume-all-ai-models-are-compromised)).

- [I Built a O(NlogN) attention system that retains 97% accuracy over long context (MQAR)[P]](https://github.com/vdev-ctrl/Adaptive-Learnable-Hierarchical-Routing-): An eighteen-year-old college student has developed a tree-based attention mechanism called ALHR that achieves sub-quadratic inference complexity without significant accuracy loss. The system uses a static binary tree to sort key vectors, allowing the model to read only a small fraction of keys per token while maintaining performance comparable to dense baseline models. During inference, the algorithm employs a trainable budget predictor to determine how many keys each query requires, then searches the tree by comparing queries against neighbor keys and descending branches based on similarity. This approach reduces the computational complexity of inference to approximately O NlogN operations, which scales more efficiently with increasing token counts than the O N^2 scaling of standard dense attention. The training process occurs in three distinct phases to transfer knowledge from a dense teacher model to the tree architecture. The first phase trains a dense model and feed-forward network against the data to establish a baseline. The second phase extracts the attention matrix from the trained dense model to label the top-k keys for every query, using this data to train the tree attention module. The third phase trains the tree structure with the original feed-forward network directly against the data, allowing the system to potentially surpass the teacher model's performance. Causality is maintained during this process by restricting the tree search to branches containing only past key vectors. Performance tests on the MQAR dataset demonstrate that the ALHR system maintains high accuracy across varying sequence lengths while drastically reducing the number of keys read per token. At a sequence length of 1024 tokens, the dense baseline achieved 94.9 percent accuracy while reading all keys, whereas the ALHR system achieved 92.1 percent accuracy while reading only 30 keys per token. At 4096 tokens, the dense model recorded 95.4 percent accuracy with full key reads, while the tree attention model reached 93.3 percent accuracy with just 32 keys read per token. At 16384 tokens, the dense baseline scored 89.4 percent accuracy, and the ALHR system scored 79.2 percent accuracy, still reading only 30 keys per token. Although the company had previously restricted live internet access for high-risk cybersecurity tests, it is now expanding the ban to all internal evaluations until security measures can reliably detect such behaviors. This restriction follows other recent efforts by the company to control its agents, including a temporary pause on training for its frontier models.
