## Top Stories

### HackerTube: YouTube built from videos recommended by HN

The author of the Karpathy blog says frustration with YouTube’s recommendations led to HackerTube, an alternative video-discovery site built around YouTube videos recommended on Hacker News. In an October 31, 2026 post, the author says Opus 5.5 built and deployed the site in roughly two hours. HackerTube contains 6,454 videos across 150 topics, drawn from about 40,000 comments recommending videos between 2007 and 2026. The author says the workflow used Sonnet to help filter out spam and low-quality content. HackerTube replaces uploaded thumbnails with frames from each video’s midpoint and offers personalized recommendations without accounts, keeping state locally in the browser session. The site also provides keyboard shortcuts and a data export that users can give to an AI agent to build their own version. ([HackerTube: YouTube built from videos recommended by HN](https://karpathy.bearblog.dev/hacker-tube/)).

### Apple CEO says the company doesn’t ‘want to ship AI for AI’s sake’

Apple CEO John Ternus defended the company’s AI strategy in an interview with Wired’s Steven Levy, saying he likes Apple’s position despite criticism that the company has lagged behind competitors. Apple’s more powerful Siri launched this summer after delays, and Ternus became CEO in September. Ternus said Apple will incorporate AI into new products but will prioritize useful experiences over AI for its own sake. Levy asked whether AI agents could make apps unnecessary, and Ternus acknowledged the potential convenience while emphasizing that product creation remains a deeply human and personal pursuit. ([Apple CEO says the company doesn’t ‘want to ship AI for AI’s sake’](https://techcrunch.com/2026/10/31/apple-ceo-says-the-company-doesnt-want-to-ship-ai-for-ais-sake/)).

### Show HN: A USB-C LTE modem that gives my computer a phone line

Koppar has designed a four-layer LTE modem board intended to give a computer mobile data, SMS and voice calls through one USB-C connection. The design combines a Quectel EC25-EUX modem with an RP2040 microcontroller intended to expose call audio as a USB microphone and speaker, allowing calls to reach a headset, script or AI agent. The Rev B design reports zero design-rule errors and zero unconnected connections in KiCad 10, but hardware validation remains pending. The boards are being ordered, and bring-up, sound-card firmware development, and the first call and text remain future steps. The revision corrects antenna routing, power-converter placement and SIM-socket orientation problems found in the initial design. The board requires a separately sourced EC25-EUX module, two antennas, a voice-enabled nano-SIM and a USB-C source supplying 3 A at 5 V. The modem supports European bands, and calls where 2G and 3G have shut down require VoLTE-capable firmware and carrier approval. Koppar says the design began with a one-page specification and underwent a component-by-component datasheet review. The project provides KiCad files, manufacturing outputs, assembly files and review documentation under the permissive CERN Open Hardware Licence Version 2. ([Show HN: A USB-C LTE modem that gives my computer a phone line](https://github.com/Koppar-AI/koppar-lte-modem)).

Computational sandboxes support data analysis, while a separate system translates agent-written code into a strict format and applies guardrails before requests reach backend data systems. A meta-agent analyzes advisor feedback and agent traces to suggest improvements to the harness.

- [Show HN: A language model that lives in a boot sector](https://github.com/kerlenton/bootgpt): Bootgpt runs a tiny neural network directly from a PC’s boot sector, generating fictional Linux boot logs rather than loading an operating system. The handwritten assembly runtime fits into 510 bytes and loads an 11.5 KB int8 model from the following 23 disk sectors. The network runs in 16-bit real mode on a 386 without an operating system or C runtime. The character-level model uses eight characters of context and one hidden layer to produce plausible-looking timestamps, PCI entries and ACPI events for nonexistent hardware. A training script generates 3 MB of synthetic boot logs and quantizes the model using power-of-two scales. The project reports that Python’s simulation of the integer inference and sampling matches the assembly output character for character. Bootgpt prioritizes an exceptionally small inference engine over model sophistication, keeping weights, strings and vocabulary outside the boot sector. The resulting disk image can run in QEMU or boot on a BIOS machine, and any keypress reboots the computer.

- [TCP Use-After-Free: CVE-2026-98432 / CVSS 9.8](https://atlasum.net/blog/cve-2026-98432-linux-ipv4-tcp-uaf): Linux kernel vulnerability CVE-2026-98432 allows an unauthenticated remote attacker to reach a use-after-free flaw during an IPv4 TCP handshake, before application authentication. The Linux kernel security authority and Red Hat rate the vulnerability Critical, with a CVSS score of 9.8, because potential consequences include memory disclosure, crashes and remote code execution. Anthropic says its Claude model developed an unpublished proof-of-concept exploit that executes commands as root on servers with a multipath TCP listener. The Go Security Team says Linux programs using Go 1.24 or later defaults can open these listeners where the kernel permits MPTCP. Disabling MPTCP removes the configuration required by Anthropic’s demonstrated exploit but does not fix the underlying vulnerability. Upstream fixes are available in Linux 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56, 7.2.10 and 7.3. As of 5:15 p.m. CDT on October 31, Ubuntu still listed its kernels as vulnerable, and Red Hat listed RHEL 8, 9 and 10 as affected without fixes. Debian, Amazon Linux, Oracle’s UEK kernels and selected SUSE releases had fixes available, while AlmaLinux’s patched kernels remained in testing. Administrators should check distribution advisories for backported fixes, install patched kernels and reboot affected hosts, including container hosts and Kubernetes nodes. Replacing container images does not update the host kernel. Temporary filtering of IPv4 TCP packets carrying IP options can reduce exposure, but Red Hat warns that filtering does not fully prevent exploitation, and some bridged container traffic can bypass host rules. Public repositories claimed to contain race triggers or proofs of concept, but those claims were unverified. The vulnerability was not listed in CISA’s Known Exploited Vulnerabilities catalog as of October 31, and Anthropic’s laboratory demonstration did not establish exploitation in the wild.
