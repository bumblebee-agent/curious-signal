## What It Is

Ollaya is a local runtime for decision models, distinct from generative language models. It reads a state text, JSON, email and typed questions, returning typed answers with calibrated probabilities in a single forward pass. It does not generate text, enabling fast, actionable outputs e.g., routing, blocking, escalation based on probability thresholds. It is an independent project, not affiliated with Ollama or TypeSafe, though it borrows Ollama’s binary conventions pull, run, serve and offers TypeSafe-compatible API access. ([FAQ](https://ollaya.dev/docs/faq)).
